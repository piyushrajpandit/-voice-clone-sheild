Privacy Policy

Effective date: November 13, 2026 · Version 1.0
Draft for Legal Review: This document outlines current system data handling practices for Voice Clone Shield. Specific corporate registrations and local regulatory designations remain pending formal review.

1. Overview and Core Principle

Voice Clone Shield processes acoustic audio signals and conversational transcripts solely to detect synthetic speech artifacts and fraudulent caller intent. We do not sell personal data, trade voice samples, or monetize biometric identifiers.

2. Audio Data Processing

When you record speech or upload an audio file for forensic classification:

  • Local Inference: Audio streams are parsed by the local application instance to compute acoustic metrics (pitch cadence, spectral centroid, spectral flatness, and spectral rolloff).
  • Neural Classification: Audio waveforms are passed to a local Wav2Vec2 transformer pipeline to compute synthetic probability scores.
  • Transcription: Speech-to-text inference is executed using faster-whisper within system memory.
  • Storage: Audio recordings are buffered in memory during analysis and are not transmitted to third-party model training networks.

3. Audit Logging and Local Database

To support incident investigations, the system records scan metadata in a local SQLite database (calls.db). Logged fields include timestamp, file identifier, composite threat score, detected scam classification, and recognized trigger keywords.

Users maintain complete operational control over logged data. The local audit database can be emptied at any time via the Clear Audit History function in the dashboard.

4. Third-Party Integrations

Optional notification features (such as automated SMS security alerts) utilize the Twilio API when credentials are configured. In that mode, destination phone numbers and brief alert summaries are transmitted directly through official Twilio endpoints.

5. Contact

For questions regarding audio security practices or to review technical architecture documentation, contact the system administrator or submit an inquiry through the verified project repository.
